# Unbound — ChatGPT Work marketplace

This repository is the public **ChatGPT Work** marketplace for [Unbound](https://uncompany.ai), the
file-native sales-execution agent by UnCompany. It serves the free tier.

## Install

In the ChatGPT desktop app, in **Work mode**, add this repository as a plugin marketplace and
install **Unbound (Free)**. The marketplace entry is at `.agents/plugins/marketplace.json` and the
plugin tree at `plugins/unbound/`.

Installation copies the plugin into ChatGPT's plugin cache and the host runs that cached copy, so
after an update, reinstall and start a **new conversation** before judging the change.

## Claude Cowork

The Cowork build of the same tier lives at
[uncompany-ai/unbound-free-claude](https://github.com/uncompany-ai/unbound-free-claude). Each host installs from
its own repository, because a marketplace is discovered at a repository root.

## Provenance

The published tree is the gate-verified build artifact of core `v1.4.0`.

## Maintenance

Every tracked file in this repository is generated by
`unbound/runtime/publish-marketplace.sh --tier freemium` in the core repository.
Nothing here is hand-maintained, and any manual edit will be overwritten by the next publish.
